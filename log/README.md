# Skill output logs

Store only authorized, sanitized output for the skill or test being demonstrated.

- `keylogger.md` documents the scope, authorization, test environment, and
  safety controls for any keyboard-event test.
- `example.log` is a harmless placeholder demonstrating log formatting.
- Do not commit real keystrokes, passwords, tokens, or personal data.
- This repository template does not include keylogging or credential-capture code.
